# kiloklustakwik — Automatic Spike Sorter

KiloKlustaKwik performs automatic spike sorting via Classification EM (CEM).
It reads `<base>.fet.<Method>.<elec>` and writes `<base>.clu.<Method>.<elec>`.

The reference (usage, options and their defaults, file naming, pipeline
stages, GPU backends) is **[doc/kiloklustakwik/README.md](../../doc/kiloklustakwik/README.md)**.
Installation: [doc/INSTALL.md](../../doc/INSTALL.md).

Running `KiloKlustaKwik` with no arguments prints every option and its
default.
