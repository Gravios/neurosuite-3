# EMG files — `-emgclean.dat`, `.emg.<probe>`, `.res.emg.<probe>`, `.spk.emg.<probe>`, `.emg.meta.yaml`

Written by [`ndm_extractemg`](../commands/ndm_extractemg.md). All binary
files are little-endian with no header. `<probe>` is the probe's `id`
from the session YAML's `probes:` section, or the 1-based spike-group
number when the session declares no probes. Under the
[variant naming convention](naming.md) the per-probe files use the
method token `emg` in place of `standard` / `stderiv`, and the probe id in
the group position.

| File | Contents | Layout |
|---|---|---|
| `SESSION-emgclean.dat` | recording with the EMG component removed | int16, `nSamples × nChannels`, sample-major (same shape as `.dat`) |
| `SESSION.emgclean` | symbolic link to `SESSION-emgclean.dat` | — |
| `SESSION.emg.<probe>` | EMG component trace | int16, `nSamples` values, one channel |
| `SESSION.res.emg.<probe>` | EMG event times | int64, `nEvents` sample indices |
| `SESSION.spk.emg.<probe>` | EMG event waveforms | int16, `nEvents × nSamples × nChannels(probe)`, sample-major |
| `SESSION.emg.meta.yaml` | per-probe model and diagnostics | YAML text |

## `SESSION-emgclean.dat`

Same size and channel order as `SESSION.dat`, at the full sampling rate.
On each probe's channels, `clean[t,c] = raw[t,c] − A[c] · EMG[t]`, rounded
to the nearest integer and clipped to the int16 range; the channel's DC
offset is kept. Channels outside every probe are copied unchanged. A
[`.dat`](dat.md) reader (e.g. NeuroScope) opens it directly. The
`-emgclean.dat` name does not fit the `SESSION.<ext>` form that
`inputExtension` selects, hence the `SESSION.emgclean` link.

## `SESSION.emg.<probe>`

The EMG component, `EMG[t] = Σ_c (raw[t,c] − μ[c]) · W[c]`, one value per
sample of `SESSION.dat`, rounded to the nearest integer and clipped to the
int16 range. No scale factor is applied. Because `W` includes the FastICA
whitening, the trace is in units of the component's standard deviation
on the high-passed identification data, so it is coarsely quantised;
event detection uses the unrounded values. File size = `nSamples × 2`
bytes.

## `SESSION.res.emg.<probe>`

Event times as sample indices into `SESSION.dat` (full sampling rate),
`int64`, ascending — the same layout as [`.res`](res.md). Each event is
the maximum of the smoothed |EMG| envelope after a threshold crossing.
File size = `nEvents × 8` bytes; empty when no event was found.

## `SESSION.spk.emg.<probe>`

One waveform per event, in `.res.emg` order: `nSamples` samples (peak at
`peakSampleIndex`) on all channels of the probe, sample-major — the same
layout as [`.spk`](spk.md). Channels are in the order the probe's
channels were gathered: the anatomical groups in the order listed under
the probe, channels in group order, `skip: 0` only. Values are raw
`SESSION.dat` samples, not filtered. Samples past either end of the file
are 0. File size = `nEvents × nSamples × nChannels(probe) × 2` bytes.
`nSamples` / `peakSampleIndex` come from the first spike group (default
32 / 16) and are recorded in `.emg.meta.yaml`.

## `SESSION.emg.meta.yaml`

Rewritten on every run.

```yaml
# Generated by process_extractemg 1.0 (2026)
samplingRate: 20000
hpFreq: 100
thresholdFactor: 5
envelopeWindowMs: 20
refractorySamples: 400        # after defaulting
spikeLength: 32               # nSamples of .spk.emg
peakSampleIndex: 16
groups:
  - id: 0                     # <probe>
    nEvents: 1234
    uniformityScore: 3.98     # |Σ A/‖A‖| of the chosen component
    eigenvalueRatio: 0.41     # leading / total eigenvalue of the high-passed covariance
    threshold: 7.4            # in EMG units
    medianEnvelope: 0.99      # median |EMG| on the identification data
    fastica:
      iterations: 812         # total over all components
      converged: true         # false: fewer than K components found
    channels: [0, 1, 2, 3]    # .dat channels, in .spk.emg order
    channelMean: [...]        # μ, per channel
    loading: [...]            # A, mixing column of the EMG component
    unmixing: [...]           # W, applied to (raw − μ) to get EMG
```

The values above are illustrative.
